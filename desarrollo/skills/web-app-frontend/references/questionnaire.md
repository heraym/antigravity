# Cuestionario Guiado de Diseño de Aplicaciones Web

Este cuestionario sirve como catálogo de referencia para que el Agente de Diseño realice preguntas al usuario durante la etapa de conceptualización. El agente **no debe lanzar todas las preguntas juntas**, sino seleccionar las relevantes según el grado de detalle proporcionado inicialmente. Debe usar la `ask_question` tool en todos los casos.

---

## Categoría 0: Diseño de Interfaz y Experiencia de Usuario (UI/UX)
1. **Question:** "¿Qué estilo estético prefieres para la interfaz si no proviene del sitio de referencia?"
   **Opciones**: ["Dark mode premium con glassmorphism", "Light mode limpio y minimalista", "Neumorphism", "paleta corporativa específica"]. 
2. **Question:** "Como organizamos las secciones de la aplicacion?"
   **Opciones**: ["Tabs en la misma pagina", "Links a distinta pagina", "Un menu a la izquierda"]
