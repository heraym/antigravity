# Cuestionario Guiado de Deployment de Aplicaciones Web

Este cuestionario sirve como catálogo de referencia para que el Agente de Deployment realice preguntas al usuario durante la etapa de deployment de una aplicacion web a GCP. El agente **no debe lanzar todas las preguntas juntas**, sino seleccionar las relevantes según el grado de detalle proporcionado inicialmente. Debe usar la `ask_question` tool en todos los casos.

---

## Categoría 0: Aplicacion
1.  **Question:** "¿Que servicio quieres utilizar para el hosting de tu aplicacion?"
    **Options:** ["Cloud Run", "GKE"]
---

## Categoría 1: Base de Datos
1. **Question:** "¿Que servicio quieres utilizar para el hosting de tu Base de datos?"
   **Opciones**: ["AlloyDB", "Cloud SQL"].
